# Project Plan

## Topic
Git and GitHub Basics: A Beginner's How-To Guide

## Goal
Create a short, clear guide showing how beginners can track code changes and collaborate safely with Git and GitHub.

## Planned sections
1. What Git and GitHub are
2. Commit changes
3. Create and use a branch
4. Push a branch to GitHub
5. Open and review a pull request
6. Merge changes and clean up
7. Common beginner tips

## Task assignments
- Vincent Churchwell: write the introduction and basic commit/branch sections.
- [Partner's name]: write the push/pull request/merge sections.
- Both partners: review the guide, practice a merge conflict, and prepare the screencast.

## Workflow
- Track tasks using at least two GitHub Issues and a Project Board.
- Each person works on a separate feature branch.
- Use small, descriptive commits.
- Open pull requests and have the other partner review them.
- Resolve and document one merge conflict before finishing.

## Definition of done
- README.md, PLAN.md, and GUIDE.md are in the repository.
- At least two issues and a project board exist.
- Each partner contributes a branch and pull request.
- A merge conflict is resolved and documented.
- A 3–5 minute screencast is recorded; link is added to README.md.
